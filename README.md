# Jetour T1 — «Комфорт» и «Jetour USB»

Два приложения для Jetour T1 с китайской штатной Android-ГУ:

- **Комфорт Jetour** — работает на самой ГУ: климат-автоматика, свой динамический экран,
  плавающий медиаплеер со всех источников, ярлыки приложений, индикаторы и другие удобства
  поверх штатного интерфейса.
- **Jetour USB** — приложение-компаньон для смартфона: ставит и обновляет «Комфорт» (и любые
  APK) на ГУ по USB, выдаёт все нужные права и настраивает систему.

## Установка

Готовые APK — в разделе [Releases](https://github.com/kzandreykz/Jetour/releases/latest):

- `JetourComfort.apk` — приложение для головного устройства;
- `JetourUSB.apk` — компаньон для телефона.

Порядок первого запуска:

1. Установите **Jetour USB** на смартфон.
2. Подключите смартфон к ГУ по USB и установите через него **Комфорт Jetour** — компаньон
   сам выдаст и проверит все нужные права (см. ниже).
3. Дальше «Комфорт» и «Jetour USB» обновляются по воздуху сами.

## Возможности «Комфорт Jetour»

**Климат-автоматика** (применяется при запуске):
- подогрев и вентиляция сидений — по температуре, с уровнями, для водителя и пассажира;
- автоподогрев руля и лобового стекла (с таймером);
- автооткрытие шторки панорамы.

**Динамический экран** — собственный рабочий стол вместо штатного (включается одним тумблером):
- живые обои MP4/WebM/GIF или фото;
- каталог живых обоев из интернета по категориям с подгрузкой и библиотекой скачанного;
- передача обоев со смартфона по Wi-Fi (через Jetour USB);
- ярлыки-плитки в стиле «жидкое стекло»: **Android Auto** (умный — если телефон подключён,
  открывается приложение Android Auto, иначе экран подключения), **Музыка**, **Бездорожье**,
  **YouTube** (в плавающем окне поверх экрана; если приложения нет — веб-версия во встроенном окне);
- настройка экрана: перетаскивание часов и сетки плиток с фиксацией, 6 стилей часов и
  опциональная **обложка трека** окошком с мягкими краями (положение и размер настраиваются).

**Медиа** — плавающий плеер поверх любого экрана: обложка, название, исполнитель и управление
(перемотка, пауза) со **всех источников ГУ** — радио, Bluetooth, USB, Android Auto и локальная музыка.

**Приборка и индикаторы:**
- плавающие литры топлива и температура ОЖ (перетаскиваются на экране);
- числовые значения рядом со штатными значками приборной панели (с настройкой положения).

**Ещё:**
- кнопка на руле открывает «Комфорт» удержанием (назначается в настройках);
- плавающая кнопка со списком приложений;
- синхронизация часов с интернетом;
- настройки с боковым меню разделов — Климат / Экран / Подключение / Приборка.

## Возможности «Jetour USB»

- установка и обновление «Комфорта» и любых APK на ГУ по USB (режим ADB-хоста);
- **автоматическая выдача и проверка всех нужных прав** «Комфорту»;
- кнопка «Выдать все права» для восстановления, если что-то отозвали вручную;
- включение динамического экрана «Комфорта» и возврат штатного лаунчера;
- передача обоев на ГУ по Wi-Fi;
- запуск и удаление приложений на ГУ;
- встроенный офлайн-резерв «Комфорта» и докачка актуальной версии из обновлений;
- самообновление.

## Права и особенности прошивки

Штатная прошивка Jetour T1 закрыта: в ней нет доступных экранов «Показывать поверх других
приложений» и доступа к файлам, нет службы живых обоев Android, а тачскрин в системных
диалогах (например, кнопка «Установить») временами не реагирует.

Поэтому **все права выдаёт Jetour USB через ADB** — один раз при установке «Комфорта», с
проверкой на ГУ. Это плавающие окна, доступ к файлам, автоподтверждение установки, служба
динамического экрана, доступ плеера к треку и разблокировка нажатий в системных меню.
Выданные права **сохраняются при последующих обновлениях «Комфорта» по воздуху и после
перезагрузки** — повторно выдавать их не нужно. Штатный лаунчер при этом не удаляется и не
отключается.

## Обновления

Оба приложения проверяют обновления сами. «Комфорт Jetour» скачивает обновление прямо на ГУ;
«Jetour USB» обновляет «Комфорт» на ГУ по ADB и обновляется сам.

> При первом обновлении Android может запросить разрешение на установку приложений из этого
> источника и показать системное подтверждение установки.
