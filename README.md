# Jetour T1 — приложения

Здесь публикуются обновления двух приложений для Jetour T1 с китайской штатной Android-ГУ:

- **Комфорт Jetour** — автоматический подогрев и вентиляция сидений, подогрев руля и лобового стекла, управление шторкой панорамы, плавающие индикаторы литров топлива и температуры ОЖ, плавающее меню приложений и интеграция Wallpaper Engine.
- **Jetour USB** — Android-компаньон для установки APK на ГУ через USB/ADB, запуска приложений, выдачи разрешений и удаления приложений.

## Установка

Готовые APK находятся в разделе [Releases](https://github.com/kzandreykz/Jetour/releases/latest):

- `JetourComfort.apk` — приложение для головного устройства;
- `JetourUSB.apk` — приложение-компаньон для телефона.
- `WallpaperEngine.apk` — неизменённый официальный Android-клиент Wallpaper Engine,
  который Jetour Comfort может скачать и установить непосредственно на ГУ.

Штатная прошивка Jetour T1 не предоставляет системную службу Android Live Wallpaper.
Начиная с Comfort 1.19 это обходится собственным динамическим HOME-экраном: можно выбрать
MP4, WebM или GIF, включить зацикленное воспроизведение и назначить «Комфорт Jetour» главным
экраном ГУ. Wallpaper Engine сохраняется как библиотека и импортёр `.mpkg`; поддержка его
закрытого Scene-рендера развивается отдельно.

Начиная с Comfort 1.20 и Jetour USB 4.8 динамический фон можно передать прямо со смартфона.
На HOME-экране Comfort включите «С телефона», затем в компаньоне выберите «Передать обои по
Wi‑Fi». Телефон и ГУ должны находиться в одной локальной сети; MP4, WebM, GIF или изображение
передаётся напрямую без облака и без ADB. Приём доступен пять минут и закрывается после
одного успешного файла.

Jetour USB 4.8 также включает для Comfort безопасное автоподтверждение его собственных
установок. Это позволяет нажать системную кнопку «Установить» программно, когда прошивка ГУ
блокирует тачскрин в Package Installer. Автоматизация действует только для установщика
Android и только сразу после запуска установки из Comfort.

Обе программы умеют проверять обновления. В «Комфорт Jetour» обновление скачивается непосредственно на ГУ, а Jetour USB может обновить приложение на ГУ через ADB и обновиться сам.

> При первом обновлении Android может запросить разрешение на установку приложений из этого источника и показать системное подтверждение установки.

На китайской ГУ нет доступного экрана разрешения «Показывать поверх других приложений».
Для плавающих индикаторов и меню приложений один раз установите «Комфорт Jetour» через Jetour USB 4.1 или
новее: компаньон выдаст и проверит нужное право автоматически через ADB. Оно сохраняется
при последующих OTA-обновлениях «Комфорта».
