# Jetour T1 — приложения

Здесь публикуются обновления двух приложений для Jetour T1 с китайской штатной Android-ГУ:

- **Комфорт Jetour** — автоматический подогрев и вентиляция сидений, подогрев руля и лобового стекла, управление шторкой панорамы, плавающие индикаторы топлива и температуры ОЖ.
- **Jetour USB** — Android-компаньон для установки APK на ГУ через USB/ADB, запуска приложений, выдачи разрешений и удаления приложений.

## Установка

Готовые APK находятся в разделе [Releases](https://github.com/kzandreykz/Jetour/releases/latest):

- `JetourComfort.apk` — приложение для головного устройства;
- `JetourUSB.apk` — приложение-компаньон для телефона.

Обе программы умеют проверять обновления. В «Комфорт Jetour» обновление скачивается непосредственно на ГУ, а Jetour USB может обновить приложение на ГУ через ADB и обновиться сам.

> При первом обновлении Android может запросить разрешение на установку приложений из этого источника и показать системное подтверждение установки.

Для плавающих индикаторов требуется разрешение «Показывать поверх других приложений».
Jetour USB выдаёт его автоматически при установке «Комфорт Jetour» через ADB.
